昨天 19:30 我參加了三創育成中心的資料圖像化課程，當初會報名是因為，工作上常常需要從資料中找到 Insight，以及後續怎麼呈現並報告給主管看。看了一下課程內容覺得還蠻吸引我便參加了。

先說對於課程內容的結論：

  1. 一開始對於初次接觸 Data clean 會碰到的問題我覺得講師說得蠻詳細的
  2. 對於工具 PowerBI 的基本操作介紹較少，課程上所說大致上都能用 Excel 快速完成
  3. 總課程時間約一個半小時，時間較短導致許多內容無法完整

講師介紹

今天分享的講師 Ning Chen，曾任 Yahoo 的分析師，現在是 台北 R-Laides 的共同創辦人。

講師此次課程上使用的是他透過 D4SG ( Data For Social Good) 中替新竹縣環保局製作便利資訊看板，其中使用到的環保署水質監測 Open Data。來讓我們透過 Microsoft PowerBI 進行資料視覺化實作。

那什麼是 PowerBI 呢？

Microsoft PowerBI 是由微軟開發的商業智慧(Business Intelligence)工具，BI 工具可以將資料轉換成商業洞察(Business Insight)。簡單來說，我們可以將資料匯入 BI 工具，從中進行分析，得出結論或預測，來進行商業決策。

據我所知道的工具還有 Tableau(需付費)、Google 的 Data studio(目前免費)。Tableau 我沒使用過，但在之前參加資策會 GA 數據課程，該堂課講師有說蠻強大的。而今天講師也有提到他覺得 Tableau 在視覺上比 PowerBI 更彈性，他舉了兩方利用 Titanic 的資料做出來的視覺化報表，大家可以比較看看。

課程上提到的基本教學

  1. ) 匯入資料

開啟 PowerBI 後利用左上角的「取得資料」來匯入想分析的資料，可以透過 Excel、CSV，也可以從資料庫中匯入。

2. ) 資料欄位與圖表工具

匯入成功後可以在右手邊找到所匯入的資料(圈圈 1 )，同時也可以看見製作圖表的區域(圖表二)

3. ) 製作圖表

後記 - 詢問講師的問題

課堂中，老師有請我們利用水質監測數據，試著找出一些自己認為可以報告的 Insight。關於這點其實我相當困惑，因為工作的時候我也問過類似相同的問題。從 GA 蒐集到許多的網站數據，但在茫茫數據海，我該怎麼找出 Insight。於是我舉手詢問講師，講師這麼回答我：

他認為在做資料探索的過程，會不知道怎麼分析，可能有兩個原因

一、Domain Knowledge 不足，如果夠了解，應該可以從知道問題，並用資料去驗證。舉例如果知道熟悉 Ubike 的人，可以知道 Ubike 下雨天的使用率很低，或是上下班時間使用率很高，便可以透過資料探索去驗證

二、資料陷阱，許多資料不一定是正確的，或是需要從中視覺化的。舉例他某次在進行分析時，發現資料的樣本數非常低外，測量方式也是錯誤的。因此他認為這份資料其實無法提供什麼 Insight。

聽完講師的回覆，其實心裡也有想到，之前並沒有很了解我們的商業模式，缺乏 Domain Knowledge 下好像真的很難發現問題。確實這部分是我需要補足的地方。

整個課程結束後，回歸到前面的結論，我覺得時間太短真的太可惜了，沒能聽到更完整的分享。但也從中發現了一個有趣的工具可以去做嘗試！
