閱讀此書的過程中，也思考確實訂閱經濟乘載新科技的迅速變化，確確實實發生在自己身上。我有訂閱 Spotify Premium，每月花費一筆小錢就能無時無刻聆聽喜歡的音樂；我也有訂閱 Nintendo Switch Online，線上連線暢玩喜愛的遊戲。

訂閱制的商業模式，對於企業來說是有非常大的好處的。過往的企業販賣產品，但卻可能因為當下獲得的訂單多寡，無法有穩定的現金流。但訂閱制的好處在於可以獲得穩定的收益，企業可以更專注在怎麼提供好的服務給訂閱者，而非一直追求訂單。

作者在此書以 2 大重點在說明訂閱經濟這個商業模式，第一是訂閱經濟如何開始翻轉現在產業，變迎來「 所有權的終結 」，第二是告訴想轉換為訂閱經濟的企業，如何具體的去執行。

所有權的終結

「 消費者需要的是把釘子釘到木板，而不是需要一把鐵鎚 」，企業漸漸意識到，使用者需要的是 「 服務 」的使用權，而非產品的所有權。因此訂閱經濟是一個好的商業模式在於，提供客製化、有價值的服務給使用者，只要使用者需要服務，就能直接使用，而不是需要去買一個產品。

如何開始轉型

要從產品導向的商業模式，轉型為訂閱制其實是需要花費一些心力的。例如商業模式的思維就要更進一步去思考消費者想要的 「 服務 」為何；而作者也提到轉型的過程在組織 ( 產品、行銷、財務、資訊 ) 上會有需要調整的地方，並提供需多具體的案例，舉凡像是 Adobe、傳統報社媒體，傳統運輸工具也都開始跨向訂閱制。

總結

就我認為，訂閱制確實是正在發生的強大商業模式，閱讀此書的時候我也開始想像，往後人們的生活可以透過訂閱服務，更專注享受服務解決生活的問題，而非需要不換汰換產品自行解決問題。對於人類未來生活的幫助確實是有大大的提升。
